bv8 observations, numba vector61, fast learner, batch scale 2, packed observations,
TD Huber delta 1. Additional return rows remain branch-uniform with replacement:
128 candidates, alongside 256 anchors and 768 agent TD rows per measured update.
Support branches only determine the reference; they do not expand the sampled loss.

For every sampled state, compute full bootstrapped targets for every recorded legal
action using the existing moving target-network convention. Set `a_ref=argmax y(a)`
(first recorded action breaks exact ties). For selected non-reference rows,
`e=(Q(s,a)-stopgrad Q(s,a_ref))-(y(a)-y(a_ref))` and use
`Huber_100(max(abs(e)-2,0))`, uniformly weighted 1.0 across decisive and outside rows.
Reference rows are excluded from the loss denominator; epsilon-inactive non-reference
rows contribute zero. Neither B8 nor the student's greedy action defines the anchor.
Original branch-family weight fields are not used in this contrast objective.

Flags: `--return-mode contrast --return-contrast-epsilon 2 --return-huber-delta 100
--return-frac .5 --return-weight 0.00053 --return-gradient-telemetry
--boost-halt-rate .02 --boost-halt-low-length-rate .01 --checkpoint-every 500000`.

and `>=1000`, with a count-weighted L<700 aggregate and overall rate. Strictly more
than 1% at L<700 OR more than 2% overall halts the run and means KILL for the arm.

configuration. At .5M report heldout decisive median `Q(fatal)-Q(best surviving)`,

absolute outside median-gap change >.5 Q; L<700 boost rate >.01. Outside gap is
`Q(B8 action)-max(other legal Q)`. The error uses dynamic bootstrap targets and
sampled rows, not a fixed training evaluation set. Missing/malformed warning
inputs or evaluator failure fail closed. .5M is descriptive except ordinary
tripwires; 1M rules are binding. Return codes: PASS=0, KILL=3, NOT_EVALUATED=2.
