# Strategy after T5 (advice, 2026-10-16)

Advisory note from the cloud session, thirteenth request. Not gate evidence. T5: per-action death
within 300 is AUC 0.73 from the 60 scalars, 0.75 from the 24 new features alone, 0.73 combined;
the T1 LAD contrast is 37%. Verdict FAIL against my bar, and I accept it.

## 1. Yes: take B8 as is to a fresh-bank Phase R under Tier 1 now

The record is consistent. Reward levers, Huber, three label designs, two return designs and
inputs computed from the current board with static opponents all failed, each for a reason that
points the same way: whether a late state is fatal within 300 frames depends on how opponents
and the own body move over the next 100-300 frames, and the dense lookahead separates these
states only because it simulates that motion. The full state is Markov, so the function exists,
but it is not readable from the ego observation at the resolution and depth a feedforward trunk
has. Every lever that tried to teach it produced caution or boosting instead, because the
network could only express a coarser rule. B8 already beats the served agent on mass by +128.7
with survival on par on every mix; the clause it failed was the champion guard that Tier 1 has
replaced. Further fine-tuning of B8 for scripted survival has a demonstrated expected value of
about zero and a real risk of damaging mass.

**Check first, in one afternoon, without re-scoring anything as gate evidence.** Pool every
probe B8's five finals already have (census round 52, the M4 look-2 banks, any later B8 rows)
and compute the Tier 1 clauses as a risk estimate: the 0.50 absolute scripted floor (B8 pooled
0.531, SE about 0.023 at 480 worlds, roughly a 9% failure by noise) and the per-seed floor of
-0.15 versus the served agent (s0 and s4 sat near -0.11 on 32 worlds; at 96 worlds, SE 0.039,
each fails about 15% of the time if that is their true value). If the combined risk is above a
quarter, say so in the Phase R pre-registration and run it anyway: the guard amendment allows no
second amendment, and the alternative is a campaign with no candidate. Pick the serving
candidate seed by the pre-registered rule, not by the floor outcome.

## 2. Tier 2 research, ranked by value per Mac-hour

Tier 2 is reported, not binding, so this runs after B8 ships.

1. **Three cheap probes on the existing bank (hours, no training)** that decide which
   architecture is worth a 20M retrain. (a) Fuse-layer probe: GBM on B8's 256-d fuse features
   plus its six Q values for the same per-action label; above 0.85 means the raster carries
   the information and the limit is value learning. (b) Motion features from the snapshot
   store replays: opponent head displacement over the last three frames, hero heading history;
   a gain above 0.1 AUC means memory or frame stacking is the direction. (c) Full-state
   features outside the ego view: bearing and distance of each opponent head to the boundary of
   the hero's component; a gain means the view is the limit.
2. **Frame stacking** (two or three previous rasters or opponent-head trails as channels) if
   probe (b) fires. It gives velocity without recurrence, and recurrence is the one
   architecture this project trained and lost with. Cost: an obs version, a 20M retrain, a
   fresh Phase R; about a day.
3. **Death-probability auxiliary head** on rollout outcomes, if probe (a) fires. Cheap to add
   (the bank has 103k labelled branches), useful for representation; folding it into action
   selection is a learned veto inside the network and needs the owner's ruling.
4. **Snapshot-restart curriculum.** Tooling exists, label-free, one arm costs about four hours.
   But if perception is the limit it inherits it; run it only after the probes say learning,
   not perception, is the constraint.
5. **Wider or multi-scale view** if probe (c) fires. A retrain, after frame stacking.
6. **Learned model with short-horizon planning**: a planner at serving is excluded by the
   ruling for Play mode. For Watch mode alone, where opponents are deterministic bots, the
   dense shadow is a 54/64 policy today; the cost is latency (about 2 s of rollouts per batch
   on one core) and the fact that it is a veto in spirit. An owner decision, not a research
   lever.

## 3. Cheap experiments that could still change the conclusion

Only probe (a). If the fuse features reach 0.85 on the per-action label, the information is in
the raster and the failures were learning failures, which reopens a label arm on the fuse-level
representation rather than on Q. Probes (b) and (c) cannot change the Phase R decision; they set
Tier 2's direction. A within-100 relabel of the same bank is free but T4c already restricted
labels to the last 100 decisions and stayed flat, so it is not decisive. Run (a) today, then
pre-register Phase R regardless of its answer.
