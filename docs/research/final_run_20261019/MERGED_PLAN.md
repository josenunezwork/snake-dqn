# MERGED PLAN — "ExIt-B8 Full-Sight": one expert-iteration run on 3 Colab L4 lanes (2026-10-19, lead advisor)

## 1. Thesis

**Core = rl_search** (verify-then-expand, survival-constrained, *deterministic* exact-sim lookahead, DAgger with a teacher-acts anneal) — the cheap form of the only teacher that has ever beaten B8 by a large margin (T3 dense: scripted episode survival 54/64 vs 38/64, alive-frame 0.942 vs 0.861, +92 mass, while flipping 75 of 301,589 decisions). **Grafted:** colab's round-0 "teacher at scale" readout as the premise gate (replacing Phase 0), death-window saturation, compact label exports with replay regeneration, 20x decisive weighting; game/rl_ongpu/rl_selfplay's full-arena tower zero-initialised into B8 (bitwise B8 at step 0, ablated with/without in round 1); rl_ongpu's hindsight auxiliary heads and checkpoint-look rule; l4g4's forbidden-set abstention + KL anchor and **no TD term**; a100's regenerable-label discipline.

**Why the others lost.** h100/a100 (GPU-sim port): every critic lens, and my own re-check, says 2–4 weeks to the first useful unit and >500 units (~50% of the balance); worse, the N8/H128 teacher they would distill is noise — I recomputed calibration-v1.json: two independent draws of the same N8/H128 search agree on the argmax 98/300 = 32.7%, 23/61 even on clear-top (>5% gap) decisions, median top-2 gap 0.6%. rl_selfplay (PPO, 2–4 B samples): every Colab GPU runtime is 12 vCPU = 6 physical cores, so realistic ingest is 10–13 k rows/s, 2.2 B samples is ~50 h single-seed on a new trainer, and fresh RL from B8 is the known failure (T23 −80.8, Q0). rl_ongpu (15x longer DQN): its ≥20 k tr/s acceptance is the ideal-case number, its L4 fallback cannot reach 300 M under the 24 h cap, and M5 showed more data hurts this recipe. l4g4's R-net twin dies more exactly where labels live, and its 85%-agreement gate is unpassable by construction.

**Decisive claim:** the GPU-shaped job in this project is not the simulator; it is *every network forward*. The run saturates three 12-vCPU L4 lanes 24/7 with the exact numba sim on the host and all forwards on the GPU. A100/H100/G4 buy the same six cores for 3.5–5x the units and are refused.

## 2. Algorithm (expert iteration, supervised projection, no TD)

**Teacher T_r** at a gated hero decision s (student S_{r−1}; S_0 = B8 s3, SHA 3e649783…):
1. Trigger: hero length ≥ 600, every 4th episode-local decision (T3 used 5th); PLUS every decision in the 150-decision window before any student death (replay that world from a snapshot; label at interval 1, continue with the teacher's action when it differs); PLUS a 3% uniform sample below L600 (drift control).
2. VERIFY: one deterministic continuation (eps 0, advisory mask, real opponents, cloned food RNG) of the student's own greedy action for H = 300 (T3's validated D). Survives → label = confirmation (a* = student action), cost 300 row-steps.
3. EXPAND (expected 5–10% of triggers): the other legal actions in lockstep for H = 300. a* = highest-student-Q action that survives (ties prefer the student's action — the T3 rule that preserves mass); none survive → longest-surviving. Forbidden set F = legal actions that die while a* survives. Mean cost ≈ 300 + 0.08·1,500 ≈ 420 row-steps/decision (vs 4,300 for Phase 0's N8/H128, 1,800 for T3 dense).
4. Every searched decision also records per-action (survive-300, alive-steps/300, 300-step mass): dense targets, not just the ~0.1–1% flips.
5. Teacher-acts mixing β: R1 = 1 (data contains the 0.8-survival regime), R2 = 0.5, R3 = 0.

**Student fit** (one L4, generalised research/redesign_m2_20261008/train_student.py; the only operation that ever produced a champion here, M2b):
- Rows: all searched decisions (obs regenerated by bit-exact replay) + a 1:1 subsample of unsearched on-policy rows. Aggregated DAgger bank, per-round weight 1.0 current / 0.5 older.
- Loss = KL(softmax(Q_prev/τ) ‖ softmax(Q/τ)), τ = 1, weight 1.0 on unlabeled rows / 0.25 on labeled (anchor to the previous round's student; B8 in R1) + hinge Σ_{f∈F} max(0, Q(f) − Q(a*) + 0.5) on decisive rows, weighted 20x + small advantage-MSE (M2b exp_advkl8). Empty F → no hinge (abstention).
- Auxiliary heads in a training wrapper only (stripped at export; gradient into trunk/tower, never through the Q head — the T4 RETURN lesson): per-action survive-300 logits (BCE, weight 0.2) from the rollout bits; hindsight death-within-64 (BCE 0.1) and log free-region at +32/+64/+128 decisions (Huber 0.2) from the stored trajectory.
- Adam, LR 2.5e-5 on pretrained parameters / 1e-4 on the new tower and heads, batch 1,024, 4–6 epochs; epoch selected by held-out decisive agreement + a 32-world fast on-policy survival probe on the fit runtime (pre-registered rule, never gate data).
- No TD, no replay, no RL polish: every fresh-Adam TD fine-tune of B8 lost mass (T3 −88, T23 −80.8, Q0, M5/M6).

## 3. Observation and network

Student **ego2s-bv8a** = ego2s-bv8 unchanged (7×31×31 local, 4×37×37 coarse, 60 scalars incl. v8) + one full-arena tower: 4 uint8 planes at cell resolution over the 145×83 arena padded to 152×88 — own-body time-to-vacate/255, other-body TTV/255, food (128 ambient/255 corpse), heads (255 own/128 enemy/64 enemy-next) — read straight off GridBatchSim's owner/slot/food grids (~5–10 µs per world-frame). Tower: 3×3 stride-2 convs 16-32-64-64 → Linear 256 + LayerNorm; fuse input 444→700 with the new columns **zero-initialised** (test: max|ΔQ| == 0 vs B8 on 10 k states). ~+12 M MAC on B8's ~11 M; Mac serving ~8–10 ms vs 5 ms. Rationale: T9 — at the decisive point the fatal pocket boundary extends beyond 15 cells in 23/42 cases and the coarse plane erases 1-cell walls; T8's 0.74 AUC was a CNN on the *existing* planes. Round 1 fits S1a (tower) and S1b (no tower) on identical labels and screens both; if the tower buys nothing, the served network is unchanged. Live source `LiveFullSight` mirrors ego_live_bv8 with sim-vs-live byte identity tests; loader gets a new arch id; aux heads never ship.

## 4. Simulator and throughput

Exact numba GridBatchSim on the host, bit-exact with the live game and the Mac gate; **no GPU sim port** (off the critical path for good). Engine = the T33 many-worlds batched teacher (compacted rings ~80 KB/row, pre-drawn streams, direct-owner v8, compiled corpse/consume, submit/collect GPU lanes) with the verify-first phases added. Measured on the Mac after T33 round 2: ~40 µs host per resident row-step with 3 numba threads, hero forward 12.5 µs on MPS; moving the forward to the L4 (fp16 trunk / fp32 head, ~1 µs/row) leaves the host as the whole cost.

Per L4 lane (12 vCPU = 6 physical EPYC cores, 2.4–3.7x slower than M5): 2 teacher processes × 5 numba threads, W = 512–1,024 root worlds each, frozen vector61 opponents batched on the GPU. Bracket: **30–60 k resident row-steps/s → 20–80 searched decisions/s per lane**. A labeled H5000 world needs ~900 searched decisions (≈720 interval-4 triggers + ≈150 death-window + 3% sample) → 80–320 worlds/h per lane, 240–960 worlds/h on three lanes. Round target 2,400 worlds → 2.5–10 h; ~2.2 M searched decisions and ~5–20 k decisive rows per round. **Benchmark go-rule: ≥ 15 dec/s per lane** (8–15: cut to 1,200 worlds/round and add the Mac's six workers after Phase 0 ends; < 8: stop and report). GPU busy will read 10–25% during labeling, 40–60% during fits; dec/s is the utilisation metric.

Optional 0.3-unit probes (prep day 1): nproc/RAM of G4 and TPU-v5e1 runtimes. If either exposes ≥ 32 vCPU, label jobs move there — the one way a pricier runtime buys more here.

## 10. Prep steps, acceptance tests, kill criteria

Prep (Sol, two worktrees, Claude reviews; no live Colab):
- **A1 teacher fidelity:** at the interval-5 clock and eps 0, verify-then-expand must reproduce T3 dense's chosen actions on the retained T3 receipts (same world seeds, checkpoint SHA) ≥ 99%, every mismatch explained.
- **A2 replay identity:** observations regenerated from (seed, action trace) byte-identical to the labeling run on 50 worlds, all three mixes.
- **A3 tower:** max|ΔQ| == 0 vs B8 on 10 k states; LiveFullSight planes byte-identical to sim planes on the P2 bank; loader arch id; export strips aux heads.
- **A4 fit harness:** with tower off and labels = B8 argmax, the fit reproduces B8 within 1e-5; unit tests for hinge/abstention/KL/aux masking.
- **A5 benchmark (L4, 20 min, ~1 u):** dec/s per lane, expansion fraction, host/GPU %, RAM, export size; go-rule ≥ 15 dec/s.
- **A6 Mac preflight** of every entrypoint on tiny inputs (2 worlds, 500 frames, 200 updates).

Pre-registration before round 0 (banks, rules, caps, selection). Kill/continue rules, one look per round:
- **Round 0** (B8 + teacher acting at every trigger vs bare B8, 160 fresh paired worlds × 3 mixes): GO = scripted no-death ≥ 0.66 (B8 ~0.55) AND pooled mass ≥ +40 with LB90 > 0 AND boost share within [0.5%, 10%]. STOP → no further spend; report B8 as the bare ceiling. (Phase 0 keeps running on the Mac untouched; its N8/H128 mass-window verdict is recorded as a cross-check, not a gate — its own interim traces show 42% boost switches and −254 mass on both-survive worlds, i.e. it tests a misaligned teacher.)
- **R1 screen** (S1a, S1b, planner arm vs B8, 96 scripted + 32 frozen + 32 mixed paired H5000): continue if the best student has scripted survival ≥ B8 + 0.03 AND mass ≥ −30; otherwise, if the planner arm ≥ 0.70 scripted survival, present Path B (below); else stop.
- **R2:** fund R3 only if R2 beats R1 by ≥ +15 mass or ≥ +0.03 survival.
- Per-job tripwires (KILL that shard/seed): non-finite loss, > 90% one-action share, boost share > 2× the teacher's own share on the bank, L<600 disagreement with B8 > 5%, held-out decisive agreement < 70%.

## 11. Evaluation vs B8

Selection: pre-registered — the round/variant with the largest LB90 pooled mass subject to scripted survival ≥ B8 + 0.03. Then the existing Mac strict gate (Tier 1 sequential Phase R + Tier 2, survival band v2 pooled_ni_continue, ~7–9 h) vs served bare B8 s3 on fresh banks, then T12-style serving qualification for the new obs spec (live identity, no veto, rollback matrix). B8 itself already failed Watch12 pacing at T12, so a **Watch6-only release path is pre-registered** rather than treated as a late surprise. Release = STRICT_PASS + SERVING_PASS + owner OK; rollback SNAKE_SERVE_CHECKPOINT=b8-s3.

**Path B (owner decision, priced, not default):** if the student misses but the planner arm passes, qualify a served asynchronous verify-only lookahead on the Watch hero (one deterministic H300 continuation of the chosen action every 4th decision at L ≥ 600 on a spare Mac core: ~300 row-steps ≈ 12–30 ms inside four 41 ms ticks; expansion only on failure, ≤ 3 ticks stale). It contradicts the 2026-10-08 "no veto" goal, so it is an explicit owner choice — but it is the only lever with a measured +0.25 survival.
