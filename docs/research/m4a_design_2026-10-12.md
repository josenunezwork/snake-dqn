# M4-A design — fix the M3-C training setup, teach the student to not need the veto (2026-10-12)

Goal (standing decision 2026-10-08): beat frp3-s12 + v8 **without** a veto.
Motivation: [m3c_m3d_learnings_2026-10-12.md](m3c_m3d_learnings_2026-10-12.md) — M3-C's
no-veto students survive 1-11% of games vs the incumbent's 63-75%, and a code review
found the setup itself pushes toward that (risk-seeking reward, short horizon,
inconsistent teacher targets, unseen eval roster).

## Arms (3 seeds each, 20M transitions, ego2s-b, init = M2b student)

Common to all arms ("setup fixes"):

| Change | M3-C | M4-A |
|---|---|---|
| Reward | v2 (+ mass term in B/L) | mass term kappa 1 (death costs the mass it destroys) |
| Kill bonus | 0.3 x victim length | 0 (kills pay only through the food they leave) |
| Death value | -3 | -3 |
| gamma | 0.99 -> 0.995 (2M-6M) | 0.99 -> 0.998 (2M-8M) |
| Training worlds | 75% scripted / 25% frozen | 50% scripted / 25% frozen / 25% mixed |
| Anchor | adv-Huber + KL to *unvetoed* teacher Q + margin to v8 label | margin to the v8 label only (`--anchor-mode v8margin`) |
| Anchor schedule | A/B short, L long | long (hold 8M, floor 0.1 at 15M) |

- **C**: setup fixes only.
- **D**: C + **on-policy v8 labels** (`--onpolicy-labels`): every hero decision is labelled by
  frp3-s12's v8 veto applied to the *student's own Q* on the *student's own states*; half
  of each anchor batch comes from these (DAgger-style; targets the "fits TRAIN, fails
  transfer" finding).
- **S**: D + **training-time shield** (`--shield v8`): the v8 action is executed with
  probability 1 until 8M, annealed linearly to 0 at 16M, then the student acts alone.
  The student experiences fewer early deaths (longer games, realistic large-body states)
  while learning from the labels; the anneal forces it to stand alone before the end.

All options are opt-in flags on `research/redesign_m3c_20261008/train_m3c.py`
(multi-actor trainer only); defaults reproduce M3-C (existing trainer tests pass).

## Evaluation (development, not a gate)

No-veto only: the M3-C probe protocol (32 worlds x frozen/scripted/mixed, final
checkpoints, advisory-mask greedy), compared with the incumbent frp3-s12 + v8
(434.9) and M3-C's best no-veto arm L (184.6). Any arm whose no-veto mean is within
reach of the incumbent goes to a registered Phase R; otherwise the arm ranking picks
M4-B.

## Measured costs

- Mac, 64 worlds, env only: v8 shield on the hero 2006 -> 1428 hero transitions/s
  (-29%); 25% mixed worlds -5%.
- Smoke (arm S config, Mac CPU learner): v8 overrides 0.2% of student decisions.
- Pod: RTX 4090 (M3-C recovery ran 15 x 20M for ~$5.5); plan
  `research/redesign_m4a_20261012/plans/m4a_pod_plan.json` (9 runs).
