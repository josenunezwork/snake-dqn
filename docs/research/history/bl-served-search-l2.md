# Big-Lever Served Search Ceiling (`L0′` / `L2′`) and PLAN_v3 Follow-Up Packages (`M0` / `B2` / `C1`), plus `X5` Bare Mac Timing (`bl-served-search-l2`)

## Question and Goal

Can the unchanged T3-dense search mechanism (`DenseTrigger(min_length=600, interval=5)`, all advisory-legal actions, depth-300 continuations, unchanged T3 ranking) plausibly clear **+40 equal-mix H5000 mass** against bare B8 s3 on a fresh paired development bank? This was development only, excluded from registered T34 verdicts, with no release, serving or strict-gate authority (`research/bl_served_search/PREREGISTRATION_L2.md`). Follow-up PLAN_v3 packages (`M0` lead census, `B2` natural-root escape library, `C1` Watch6 dense-vs-bare paired sessions) and the `X5` bare-B8 Mac timing adapter were prepared in the same lineage.

## Final Verdict and Key Numbers

**Mac `L2′` (160 paired H5000 worlds vs bare B8 s3) — `FUND_SYSTEMS`** (`docs/research/results/L2prime_mac_analysis_20261022.json`; label map `plan-v2-wp1/v1`):

| Mass integral | Estimate | LB90 | UB90 |
|---|---:|---:|---:|
| Frozen (`n = 64`) | `+56.12` | `+34.81` | `+77.44` |
| Mixed (`n = 64`) | `+27.60` | `+12.11` | `+43.09` |
| Scripted (`n = 32`) | `+165.27` | `+114.77` | `+215.77` |
| Pooled-equivalent | **`+83.00`** | **`+64.12`** | `+101.87` |

- Survival (reported, not a gate): pooled no-death-episode delta `+0.198` (LB90 `+0.153`); alive-frame fraction `+0.075` (LB90 `+0.058`).
- Action changes per mix: `54` frozen / `21` mixed / `79` scripted (`0.18` / `0.07` / `0.52` per 1,000 decisions); productive rescues `13` / `5` / `10`; newly caused deaths `0` in every mix.
- Fable's 2026-10-22 advice: quote frozen/mixed `+28` to `+56` mass times delivered fraction rather than the pooled `+83` headline as a product expectation (`docs/research/advice/2026-10-22_L2prime_fable_advice.md`).

## What Was Learned

- The offline dense-search ceiling over bare B8 s3 is real on this bank (`FUND_SYSTEMS`, all per-mix LB90 > 0), but it is an unpaced ceiling, not delivered serving value (`docs/notes/big-lever-experiments.md`).
- L4 placement of this exact search was not admissible on measured rates (stock-hook ruler `0.166` vs `2.18` batches/s); the Mac amendment was the path that produced the result.
- Snapshot-based branch workers must carry the process-wide game configuration: restoring only `sim.cfg` and carry leaves a fresh worker on mechanics v1 defaults (`B2_RESTORE_CONFIG_ERRATUM_20261022.md`).

## Why It Closed / Current Status

**L2′ closed `FUND_SYSTEMS` (development only).** Co-resident serving of the C15 controller failed M1 (`KEEP_B8`), and B2/C1 were prepared but not run within these sources. Served search later reached Watch through precomputed exact-stop replays (see [`watch6-confirmation.md`](watch6-confirmation.md)).
