## Resume, canaries and placement

One immutable completed unit is one full 64-root worker schedule. Publish its
payload/SHA/completion marker only after all 64 finish. A partial schedule
publishes no completed unit. Ledger namespaces bind bank, platform and full
F1 source commit. The initial attempt uploads an empty ledger. Completion
loads exactly verified schedules, checks host nproc/model and frozen root IDs,
and never recomputes them. Mac union refuses duplicates, foreign banks,
platforms, source pins and INVALID attempts. No completion is automatic.

One original plus at most two mechanical completion attempts is allowed only
after verified failure/stop and missing-unit checks. Fresh manifests, output
paths and receipts are mandatory. Every attempt, including setup/failure,
shares its original stage and series caps. Deduct prior wall/units/reserve
liabilities before preparing a completion; insufficient headroom means stop.
A source implementation change requires fresh code qualification/proof, not a
resume ledger from the old implementation.

CPU and L4 each run an excluded same-pin, same-hardware family probe before
binding main. Each probe uses the first frozen root across all three worker
schedules and exercises the same immutable config export path with
`transport_probe=true`; probes cannot enter a science ledger. Binding invokes
the qualified source/hardware/input/scanner/release verifier. No live PASS is
fabricated. The L4 pack requires the hash-bound current qualification registry,
PASS acceptance and Mac-verified L4 final transfer for CLI tree
`d0d92bdb572b770284a1fea6152417ffa5f06bea`. Otherwise L4 is NOT_RUN and no L4
manifest is emitted. A later qualification drift is a dispatch refusal.

Progress is emitted about every 110 seconds. No completed timed root for 300
seconds is an operational worker stall: terminate the incomplete config, export
the stall diagnostic and refuse that platform for production this week. Every
supervisor CLI call is also inspected: any failed or budget-exhausting call,
even recovered, conservatively excludes its platform. An unmeasured census,
incomplete matrix, INVALID unit or unverified release cannot establish placement.
All attempts/probes must be passed to the Mac analyzer so a later successful
run cannot erase an earlier fault.

For each no-fault complete platform, use the maximum measured labeller roots/h
among the frozen three schedules (ties: one, half, all). CPU ≥25% of L4 means
CPU takes all three label slots; otherwise L4 labels and CPU overflows. A
platform with any observed stall/fault is excluded this week. L4 NOT_RUN permits
a reported CPU-only ruler with no invented ratio. This x86 placement comparison
supplies no Mac-worker-hour conversion; F0 admission remains independently
pending complete allocation and measured Mac equivalence.
