## Compared labels and scope

The question was whether two label packages would differ on exactly the same
teacher-visited states under an equal, later paired-learning protocol:

- **Raw control:** stationary native H4 under the original world RNG, maximizing
  total food and then early food. It deliberately retains privileged labels and
  any conflict, so it is a scientific comparator rather than a qualified teacher
  or promotion candidate.
- **Common target:** the final receding-teacher consensus from the same original
  FOOD training bank, using eight reused future-RNG donors.

Both packages cover only the 384 cases (1,536 four-step rows) from training
worlds `2026097401`–`2026097416`. They share the exact non-label arrays:
tactical and strategic observations, scalars, action mask, case index, and
step. No RECEDING held observation, target, or gameplay example was used to
construct a training label, and no held oracle was queried.

The global EARLY source cache does include held provenance records. Those were
authenticated and filtered to the training cases before any lookup; that is not
a claim that held provenance was never read.
