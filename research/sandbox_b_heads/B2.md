# Sandbox B-2: bounded successor-head development sweep

Sandbox B-2 is the prospective, one-A100 successor to B-1's frozen-B8 head/loss screen.  It is designed to remove the duplicated loss-weight grid and test the concrete causes identified in Argon's review: limited cosine gain movement, unpenalized selectable unknown/illegal actions, unbounded all-pairs pressure, a non-supervised gated head, mismatched soft-KL protection, and row-heavy sampling.  Its only outputs are `simulator-D` development evidence.  It neither reads F5 data or evaluation worlds nor authorizes a gate, a serving change, or a release.

This package follows the [Standing A100 Development Sandbox rule](../../docs/research/governance_a100_sandbox_20261026/ADOPTED.md).  It must use the existing Sandbox Input Registry and the *same* parent-stable salt as B-1, `a100-dev/sandbox-b/split-v1`, so that its development split is comparable.  A parent belongs to validation when the first eight SHA-256 bytes of `salt + "/" + parent`, interpreted big-endian, are divisible by five.  Rows and lives never cross that parent split.

## Fixed finite design

Each fit keeps survival weight at one.  The four ordinary-to-survival ratios are therefore the complete effective loss-weight grid: `0.5`, `2`, `8`, and `32`.  The 48 configurations are the Cartesian product below.

| Dimension | Fixed values |
|---|---|
| Residual head | `normed_linear`, `cosine_fastgain`, `supervised_gated_normed` |
| Loss | `kl_pairs`, `hinge_top` |
| Ordinary:survival ratio | `0.5`, `2`, `8`, `32` (`w_surv = 1`) |
| Protocol | `500` updates with `row_uniform`; `1500` updates with `decisive_life_balanced` |

All fits use Adam with base learning rate `0.003`, batch size 512, seed 3403, and cosine learning-rate decay across the declared update count.  The finite endpoint is 48,000 updates: 24 short fits at 500 updates and 24 long fits at 1,500 updates.  Frozen B8 features are cached once on the selected device.

`normed_linear` L2-normalizes the 256-dimensional B8 feature and applies a zero-initialized linear residual scaled by 8.  `cosine_fastgain` L2-normalizes both the feature and learned directions; its gain and bias optimizer group runs at ten times the base rate so that B-1's 250-step gain ceiling does not apply.  `supervised_gated_normed` multiplies a normalized residual by a learned danger gate.  The gate receives normalized features, normalized length, and `log1p`-scaled base-action margin; its residual terminal layer starts small and nonzero, avoiding B-1's zero-initialization saddle.  Its BCE target is one for decisive rows and zero for ordinary or safe-base rows.  Evaluation uses the implementation's fixed gate logit threshold of zero for this head; it does not add a separate gate-threshold grid.

`kl_pairs` combines ordinary-row KL with all survivor-versus-bad softplus pairs.  `hinge_top` instead uses a decisive-row top-survivor/top-bad margin plus an ordinary top-1 hinge and 0.1 KL term.  In both losses, `bad = selectable & ~survivor`, so selectable unknown or illegal actions receive downward survival pressure rather than being unsupervised.  The decisive-life-balanced protocol draws exactly half each minibatch from decisive rows and half from the complement (with a deterministic odd-row remainder), weighting lives equally within each stratum.  It is a declared sampling rule, not result-driven selection.

## Evaluation and exports

Every trained checkpoint is evaluated without retraining at the exact base-action switch margins `tau = 0, 0.1, 0.2, 0.4, 0.8`.  A residual override is accepted only when its selectable action exceeds B8's base action by **more than** `tau`; an exact tie keeps the base action.  This produces 240 configuration-by-threshold rows.

For every row, the runtime reports micro rescue retention, life-macro rescue retention, ordinary harm count, ordinary-harm proxy, ordinary count, ordinary flip rate, and life-macro ordinary harm.  `pareto.json` retains the points not dominated jointly on higher micro retention, higher life-macro retention, and lower ordinary-harm count.  The ordinary-harm measures remain conditional development diagnostics, not a natural-deployment harm rate.

The result directory will contain per-configuration checkpoint bundles, SHA-256 sidecars and completion markers; `results.json`, `results.csv`, `pareto.json`, `timing.json`, `checkpoints.tar`, and the terminal `verified-ledger.json`. ## Resume and evidence boundary

The B-2 namespace is `a100-dev/sandbox-b/heads-v2`, with allocation `split-v1`.  Each of the 48 configuration IDs has a fixed allocation index and an immutable tar unit containing its checkpoint, report, internal hashes, and frozen identity.  The recipe fingerprint binds admitted input and B8 hashes, salt, seed, base learning rate, batch size, update override, smoke selection, full configuration list, and implementation hashes.

The first attempt begins with an empty committed ledger.  After a verified mechanical failure and verified stop only, the Mac may build a replacement ledger from completed unit markers and bundle path/size/SHA metadata.  It does not inspect checkpoint or report outcomes.  A continuation restores and verifies only units with the same namespace, allocation, fingerprint, index, identity, size, and SHA; it refuses duplicates, corrupt bundles, foreign recipes, and missing identity.  At most two outcome-blind completion attempts may follow the original attempt.  Each has a fresh packet, output directory, and receipt.  The runtime never allocates or retries itself.

The timeout is a generous technical runaway guard, not a time or Colab-credit budget: 60 minutes base and 120 minutes effective, including setup and export.  The packet expresses the supervisor-required accounting ceiling using the same 120-minute guard; it must not be interpreted as an economic stop.  Sandbox B-2 retains the standing crossing limit of one future frozen checkpoint SHA.  Any crossing still requires its own committed registration, judge review, fresh salt-derived paired Mac bank, publish-before-read discipline, one look, Mac strict gate, serving qualification, and owner release.
