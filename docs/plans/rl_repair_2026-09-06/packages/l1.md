## Implementation / execution steps

1. Dispatch by validated algorithm/head contract, retaining all DQN behavior. Expose policy logits/probabilities and critic value with honest inspector labels.
2. Add the paired algorithm-control harness using immutable common opponent manifests, hero assignment, world/mask/reward/observation semantics and independent training seeds. Report both data and compute budgets.
3. Freeze inference action selection in the comparison protocol (deterministic greedy for both unless a separately labeled stochastic evaluation is planned).
4. Rerun E2 strict receipt and row/mask identity cases after these shared files change. Generic PPO promotion is unavailable until this integration gate and candidate-specific serving receipt pass.

## Acceptance evidence

- PPO checkpoint load/act/serialize round trips and bad head/contract combinations fail. Human/AI row identity and masks agree across engines.
- Existing vector/v2/v3 DQN values and labels remain correct. Frontend tests/build pass; inspect the affected labels.
- Comparison harness counts training seeds correctly, uses fresh evaluation worlds and never copies/promotes a winner automatically.
