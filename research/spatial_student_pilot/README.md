# Spatial student pilot

Frozen v1 mechanism pilot. Start with REGISTRATION.md and its two pre-data
clarifications. This package has no serving integration and grants no release.

`observation.py` reconstructs 16 full-arena planes and 36 scalars from compact
ordered body/food shards. `model.py` implements the random 2,299,430-parameter
U-Net. `collect.py`, `search.py` and `fit.py` provide natural B8 collection,
two-suffix H300 labels and 4k BC +4k improvement updates. `run.py` is the actual
entrypoint for the main, 15-minute integrated ruler and tiny Mac preflight.

`resume.py` publishes immutable deterministic units, and builds an outcome-blind
verified ledger from downloaded exports and stopped supervisor receipts. Resume
only missing units and the latest eligible full optimizer/RNG snapshot; never
combine development units with science. Every attempt uses fresh directories.

`prepare.py` seals a packet from a full committed pin, clean Python 3.12 import
proof and canonical comparator hashes. Run its printed dry-run command first.
The H100-first/A100-fallback ruler is a real family canary with a short-canary
resume exemption; it transports the exact science input bytes without importing
scientific units. Main admission needs both actual same-pin hardware receipts,
and passing mature-support, <=34GiB memory and six-hour integrated forecast
checks. No receipt is synthesized and no tool here dispatches automatically.
