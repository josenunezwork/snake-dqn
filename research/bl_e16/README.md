  gamma1/GAE.995, actual next-state bootstrap, death/H5000zero, LR1e-5 encoder/1e-4new.

  state, history, counters, action windows, CPU/CUDA RNG. Interrupted execution has
  a new create-only output directory and the same bound plan; no automatic retry.
- Whole-life pairedH5000 evaluator with parent, B8 and every admitted arm on96fresh
  worlds/mix; each worker owns the whole paired world; deterministic ordered merge.
- Exact mass ledger, fixed deathframe×lastlength strata, productive rescues, induced
  deaths, all-world collateral, J/G, simultaneous one-sided bounds and Holm J check.
- R/S/P are gated implementation stubs. Even fulfilled scientific prerequisites do
  not turn a stub into an executable arm or a zero-valued leaderboard entry.
- Immutable payload/.sha256/.complete exports use the existing E2 exporter. Supervisor
  schema/export tests execute locally. No protected implementation was edited.

## Identity and admission

bank.py allocates the finite signed-int64 phase vectors, never uint32 reset PRNGs;
exhaustion refuses. Training critic/actor banks and timing/preflight are disjoint from
the288evaluationworlds. BANK/SEED_AUDIT were committed before any E16 gameplay.
The freshness audit fails on missing inventories, aliases without public coverage,
or collisions, pruning the prohibited live study before traversal.

admission.require_execution_plan verifies sidecar-complete plan, nominated F/B8
identities, exact E3/E14 architecture, E12 parent qualification, frozen blocks,
E4/full-policyH5000timing and affordable total forecast. It pins E16 registration,
implementation and borrowed execution dependencies. A `bl-e16-prerequisite/v1` adapter
binds original receipt exports under `sources`; it is an explicit operator-audited
schema bridge, not a replacement or inference from another experiment's GO.

A plan has schema `bl-e16-plan/v1`, statusADMITTED, scientifictrue, arms[A,G], commit,
source_hashes, parent/b8/bank/audit bindings(path+sha256), G_architecture/use_history,
critic_transitions2000000, actor_transitions4000000, receipts keyed E2_F/E12_parent/E4/
episode_rate/E3/E14 and an exact forecast(). Recognized architectures are the constants
G_HISTORY/G_NO_HISTORY in admission.py. All required receipt adapters and their source
exports must be included with sidecars in the supervisor upload. No plan is fabricated
while upstream results are absent.

An arm's newly refitted critic additionally requires a `bl-e16-critic-qualification/v1`
PASS receipt bound to the generated critic-ready.pt SHA before actor unfreeze. This
requires the separate E12 qualification producer; parent E12 is not enough. An absent
receipt preserves full state and reports INCOMPLETE. It is not a scientific KILL.

`runner train` requires --plan/--bank/--seed-audit/--b8-checkpoint/--parent/--arm/--output,
optionally --resume and --critic-qualification. Resume cannot change bound identities.
Output paths must be fresh. Exact CLI help is available without gameplay. `evaluate`
requires final endpoints and training_status bindings (each sidecar-complete) in a
pre-readout frozen evaluation plan. Parent nomination and source plan must remain
unchanged; do not rewrite a hash-bound training plan to add outcomes. The separate
--endpoint-lock is a sidecar-complete bl-e16-endpoint-lock/v1 object binding plan_sha256,
arms, efficacy_unread=true, endpoints and training_status. It is frozen before scoring;
the original training plan stays unchanged.
