## What the project is
- [file 2026-10-25] snake-dqn is a reinforcement-learning project for a multi-snake, slither.io-style arena whose agents train with DQN-family methods. — src: README.md:1-4
- [file 2026-10-25] A FastAPI + React web app streams server-side games to the browser, where a user can watch the trained agent or play against it. — src: README.md:4-6
- [file 2026-10-25] No repository command replaces the served checkpoint silently; releases are explicit and need the owner's OK. — src: README.md:6-7
- [file 2026-10-25] The PyQt5 desktop GUI was retired in favour of the FastAPI + React/TypeScript web UI; the platform uses PyTorch for model/training. — src: AGENTS.md:126-127
- [file 2026-10-25] Three model stacks live side by side: Apex (distributed Apex DQN, PER + target net + n-step, `ApexNetwork`, `vector61`, Python `GameState`), ego2s-bv8 CNN "B8" (distilled DQN / dueling CNN, `Ego2sNet`, ~1.64M params, `GridBatchSim` numba cell-exact sim, ego2s-b raster + 60 scalars; served), and Raster/PQN (PQN Q(λ), no replay/target/PER, `RasterDuelingNetwork`, `raster31v2`, NumPy `BatchSim`). — src: AGENTS.md:129-135
- [file 2026-10-25] B8 is the ego2s CNN, not the Apex MLP; the raster/PQN stack is not promoted. — src: AGENTS.md:129 | AGENTS.md:137-139
- [file 2026-10-25] `src/scripts/tournament_eval.py` is the shared evaluation/promotion tool (`--engine live` for vector61, `--engine simd` for raster31v2); diagnostic runs are `authority: "diagnostic-only"` and strict promotion is a separate live-only Mac mode whose passing receipt does not change the served default. — src: AGENTS.md:139-140 | README.md:85-89
- [file 2026-10-25] docs/ml_algorithm.md scopes itself to the Apex vector stack (`ApexNetwork` + 58/61-D state) and does not prescribe the released B8 policy. — src: docs/ml_algorithm.md:9-15 | docs/README.md:18

- [file 2026-10-25] Legacy Apex training entry is `./venv/bin/python src/main.py --headless --episodes 100000`; the vector61 line is frozen for new governed studies. — src: README.md:77-79
- [file 2026-10-25] B8 lineage (GridBatchSim + ego2s raster, distil then RL) comes from `research/redesign_m4*` and `research/redesign_t7_phase_r_20261016`; current work is in `research/t34_*` packages. — src: README.md:82-84
