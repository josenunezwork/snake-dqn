## Resident execution and exactness

Collection uses one E1024 simulator. The original eight logical128-world demo
reservoirs and per-world two-root heaps remain separate. Changing physical batch
size must not change priority eligibility or which records reach the dataset.
Accepted candidates are determined first in the original row/heap order. Accepted
rows are gathered once, only live body spans cross the device boundary, and each
CPU observation/snapshot is trimmed to its previous exact shapes and field bytes.

Search and assessment use1024-job slabs, with256-root immutable label units
(the last assessment unit has128 roots). Jobs may be sorted by immutable roster
identity for locality and are scattered back to their original descriptors.
A single vector61 runtime owns every world's original controlled slots, carry
and selector state. Frozen forwards are grouped by checkpoint identity, with one
combined v8 pass, and scripted/random-safe slots retain their original descriptor
and per-world counter RNG. All consumers read the resident simulator directly;
no per-roster full-body _sim_view copies are needed. R2 live-span windows and
state-generation invalidation retain their original mechanics.

Batch changes can perturb fp32 Q near ties. The optimization never rounds Q,
adds epsilon to scores, switches precision, or changes lowest-action-ID argmax.
Rows with any adjacent sorted legal Q pair within1e-5 are re-evaluated with the same
single-row fp32 network forward, independent of outer batch. This also covers
v8's restricted eligible subsets. Existing restore near-tie diagnostics remain.
Exact mapped E128/E1024 simulator/branch/record fixture tests and real-network
fixture checks are required; a non-tie action mismatch fails qualification.
These finite fixture proofs do not assert universal CUDA arithmetic identity;
same-pin CUDA qualification remains required and Mac strict/serving stays separate.

Fresh B8/student gameplay uses one E384 simulator with duplicated per-world
initial keys and arm-specific actions selected by torch.where. Full-horizon mass,
alive fractions and action counts retain paired world IDs. Student inference is
bounded to at most128 rows to preserve memory; only student rows are rasterized.
Terminal compaction never removes dead-frame zero contributions.
