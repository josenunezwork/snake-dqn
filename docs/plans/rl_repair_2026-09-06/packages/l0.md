## Implementation / execution steps

1. Use the same spatial trunk topology/capacity exactly, including initialization and normalization with separate actor and critic outputs; report any parameter-count difference. Do not edit RasterDuelingNetwork or its behavior.
2. Implement categorical masking, on-policy rollout log probabilities, clipped PPO objective, value loss, entropy, advantage estimation and minibatch accounting. GAE death/truncation/invalid-row semantics must follow the shared episode contract.
3. Use P2 rollout policies so the later comparison can use fixed common opponents and identical hero-assignment/reset rules. Changing snapshot exposure is not part of the initial algorithm control.
4. Record algorithm/head semantics explicitly. PPO logits are not Q-values. This package writes no generic serving/evaluator files; L1 integrates its checkpoints later.
5. Freeze exactly the same v3 preprocessing and convolution/fusion trunk topology, width, depth, normalization and initialization as corrected PQN. Predeclare the unavoidable categorical actor/scalar critic versus dueling-Q output-head differences. Do not widen or retune the trunk in the algorithm control; any proposed trunk change is a separately named architecture experiment.
