## Candidate (one implementation)

Base: qualified I0 runtime pin `968f02765f7c86ca27d2947347896e2fe4e6ce23`.
The candidate commit adds `r2_cache.py` and routes R2-registered simulators
through it. A simulator that is never registered runs the pinned code paths.

* **L1 live windows.** Ring gathers read `B = min(cap, round_up(max seg_count + 2, 256))`
  logical offsets (`v8_device._body_cells`/own view, `_post_body`, release map,
  post-tail paint; `masks_device.advisory_mask`; `vector_device._body_view`;
  `ego_device._ttl_by_owner`). Ring storage stays 10,400 slots; `cap` stays in
  the advisory rank encoding and in every ring modulus. `torch._assert_async`
  guards `max seg_count + 2 <= B` on every window use.
* **L2 per-state memo.** A generation counter, bumped by `step`, `prepare`,
  `_respawn`, `_maintain_food`, `realistic_benchmark._resident_reset`,
  `clone` and `repeat_interleave`, keys one advisory mask, one per-slot
  occupancy plane/count, one TTL map and one window per state. Hero and
  opponent `v8_decide`, scripted anchors, vector61 masks and vector61 free-space
  flood share them. `GPU_SIM_R2_DEBUG=1` (or `enable(sim, debug=True)`)
  recomputes every cached value with the pinned full-capacity code at every
  lookup and raises on any difference.
* **L3 device constants.** Cardinal/turn/priority/log tables are cached per
  device instead of host-copied per call (v8, masks, anchors, ego, vector61,
  `DeviceSim.step`).

The R2 mode lives in a weak side table, not in simulator attributes, so the
persistent-state inventory and digests are unchanged.

## A100 packet (step 4) — unchanged I0 ruler, I versus I′

Both arms are built by the admitted I0 engine factory (MOVE2 indexed, native
geometry, static flood, ordinary v8). `I` = pinned paths; `I′` = R2. Cells in
I0 order: E1024, E256, E64, E6 × {frozen, mixed, scripted}; then the
**exception-heavy fixture packet**: `exc-{frozen,mixed,scripted}-e256`, the
long fixture with `r2_identity.exception_fixture` (boost-burn-ready snakes;
stale dead rows plus ready respawns; a forced body collision with corpse food
and kill credit) and every ring wrapped, applied identically to both arms.

Per cell: native parity first (I0's MOVE2/geometry proof via
`integration_native.run`, then the R2 CUDA twin tests `test_r2_padding.py -k cuda`);
an identity proof of 3 progressing ticks per arm with `I′` in debug mode
(outputs + state, padding included); 3 warmups per arm; 3 interleaved
reset-inclusive plain repeats in orders (I,I′), (I′,I), (I,I′) — the sole scored
clock; for `cell-*` 3 exclusive-stage diagnostic ticks per arm (diagnostic,
reconciliation recorded, never scored); for E1024, three interleaved 32-tick
continuous blocks after 3 warmups; one profiler trace per arm for every E1024
cell (diagnostic). Every plain/diagnostic digest must be one value shared by
both arms and all repeats; continuous final digests must match across arms.

Acceptance, frozen here and implemented by `r2_analyze.py`:

* (a) identity: any native failure, unit identity failure or unexplained
  difference is **INVALID**; round-28's bounded-repair and
  two-consecutive-INVALID rules apply.
* (b) **R2_ADVANCE** only if `1 − median(I′)/median(I) ≥ 0.15` on every E1024
  roster's plain tick and the exception packet ratio
  `Σ median(I′) / Σ median(I) ≤ 1.10`; otherwise **R2_STOP**.
* (c) Q4: **PASS_SPEED** only if every `I′` continuous block on every E1024
  roster is ≥ 2,000 world-steps/s; otherwise **STOP_SPEED**.

Precedence INVALID > INCOMPLETE > decision. The E6 floor and the per-world
slope `(t(E1024) − t(E64))/960` are reported separately, not as bars. A’s
3,400–5,000/s figure is a hypothesis, not a bar.
