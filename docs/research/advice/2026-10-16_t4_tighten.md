# TWO_SIDED readout: reference for (c), tightening design, plan (advice, 2026-10-16)

Advisory note from the cloud session, eighth request. Not gate evidence. Numbers are the local
session's T4a post hoc table and the T3 diagnostics appendix.

## 1. Is 53% outside-bank change bad? Only against a drift reference

TWO_SIDED learned the bank (decisive 88%, counter 16%, agree 93% / 99.9%) and cut the growth
loss from -460 to -135 length units. The 53% in (c) is uninterpretable on its own: the late
game action landscape is flat (median gap 0.45 Q), so any perturbation flips many near-ties,
and an 8M fine-tune is a perturbation. Two references, both cheap because the CTRL
trajectories, the matched state sample and rowwise inference already exist:

- **Same-init drift (the right baseline).** B8_sk versus CTRL_sk on CTRL_sk's own states at
  L >= 700, matched as (c) is. This is what plain fine-tuning does to these states with no
  labels. If it is 40-50%, TWO_SIDED's 53% is at the noise floor and (c) cannot be read as
  spillover. If it is 15-25%, the excess is real. Five finals, one replay pass, under an hour.
- **Consequential change.** Count a flip only when CTRL's gap between its argmax and the arm's
  argmax exceeds 0.3 Q. Near-tie flips are not behaviour changes on a flat landscape. Report
  this alongside the raw rate for every arm and for the drift baseline.

Cross-seed CTRL versus CTRL is not a reference: different inits are different policies.

## 2. Tightening, ranked, with the numbers to pre-register

1. **Restrict decisive labels to the last 100 decisions before death.** T1's median LAD horizon
   is 100 decisions. Rows 100-300 decisions out are "decisive" only under B8's continuation and
   are the least distinguishable from ordinary states; they are the likeliest source of
   spillover. Keep rows within 100 at weight 1.0, rows 100-300 at weight 0.3. Offline filter on
   the existing bank (decision index and death decision are stored); no new rollouts.
2. **Outside-bank counter rows.** Sample states from the CTRL and B8 probe trajectories at
   L >= 700 that are at least 300 decisions from any death, matched to the decisive rows on
   length bucket and -max Q decile, ratio 1:1 to decisive rows. Label with B8's own action under
   the single-action margin, but at **margin 0.0-0.1 and weight 0.5**: these rows say "keep the
   argmax here", not "widen the gap", because a 0.3 margin on ordinary states would sharpen B8's
   near-ties into a new distortion. In-window counters stay at 1:1, margin 0.3, weight 1.0.
   Label noise is negligible: the late hazard is about 0.15 deaths per 1,000 decisions.
3. **Do not raise the in-window counter weight.** Counter agree is 99.9%, so those hinges are
   satisfied and carry no gradient; weight changes nothing.
4. Distance weighting beyond item 1 and single-action decisive labels: skip.

Pre-registered readouts for the tightened arm (TWO_SIDED_T, five seeds, 8M, same rule): (c)
consequential-change rate within 10 points of the same-init drift baseline; shared-survivor
length delta at 5000 >= -50; decisive agree >= 0.85 on the retained rows; counter agree >= 0.95
on both counter sets. Survival and mass verdict unchanged.

## 3. Plan: tighten first, then the fork stays as declared

The inputs separate decisive from counter rows, so the information exists; what is still coarse
is the function learned around them. Neither return regression nor expert iteration fixes
that on its own: return regression changes target magnitude on the same states, expert
iteration changes which states, and both would inherit the spillover. Insert the tightened arm
before either. Then:

- (c) falls to the drift baseline and round-65 survival moves without a mass fail: expert
  iteration with the tightened recipe is next, as planned.
- (c) falls but survival does not move: return regression next, with outside-bank branches
  rolled out too, which is the principled form of item 2 and supplies "greedy is fine here"
  targets with magnitudes.
- (c) does not fall even with outside-bank counters: the boundary is not expressible from bv8
  at this capacity, and the campaign moves to inputs.

If the pending round-65 verdict already shows TWO_SIDED passing survival with mass >= -30,
run the tightened arm anyway as the attribution control; the -135 length delta says the mass
clause is close, not clear.

## Addendum after the round-65 verdict: TWO_SIDED is KILL

Primary -0.027 (seed SE 0.045), mass vs CTRL -24 / -41 / -15, vs incumbent +154 / +99 / +75,
decisive agree 0.93, counter agree 0.999, re-rolls fine. The labels were learned and the growth
loss is mostly gone; survival did not move. TWO_SIDED stays KILL in the record.

**Does the evidence support whack-a-mole?** It is consistent with it but does not yet
distinguish it from two neighbours: (B) coverage, the student's deaths were never in bank-like
states even before training, because its trajectory differs from B8's; and (C) delayed death,
the student takes the labelled escape and dies a few hundred frames later in the same
enclosure, which episode survival at H5000 cannot credit. Three checks from the round-65 probe
rows and one short CPU job separate them:

1. **Paired world death matrix.** For each seed and world, CTRL died / TWO_SIDED died, with
   death frames. Whack-a-mole predicts fate swaps in both directions (CTRL dies, TWO_SIDED lives
   on some worlds; the reverse on others). Same worlds dying at similar frames (within 200)
   means the labels changed nothing about fate. Minutes.
2. **Alive-frame versus episode delta.** If alive-frame survival rose while episode survival did
   not, deaths were delayed, not avoided: reading (C), the pocket problem.
3. **Bank coverage of the student's death windows.** For the last 300 decisions before each
   TWO_SIDED death, nearest-neighbour distance in the 60-scalar vector to the decisive rows, and
   whether the student's -max Q rose before death as B8's did (AUC 0.85). Far from the bank with
   the fuse still firing is reading (B) or whack-a-mole; near the bank is (C).
4. **LAD check on 20 TWO_SIDED deaths** with the dense shadow, as T1 did for B8. If most have a
   surviving single action within 300 decisions, expert iteration has something to label. If the
   escapes have become multi-step, single-action labels cannot carry the skill and the next lever
   is the snapshot-restart curriculum. About one CPU-hour.
