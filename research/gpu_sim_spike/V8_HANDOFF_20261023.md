## Implementation and scope

`vector_geometry.{py,cpp,cu}` adds an explicit runtime adapter. The CPU fallback
hoists a single ring view per feature call; native mode emits all selected rows'
0–57 columns in one indexed dispatch and delegates 58–60 to the existing static
FLOOD path. It avoids the parent 64-row geometry launches and broadcast body/action
temporaries. The first native version scans each row serially, with rows parallel
across worlds; it does not claim the speed of a tiled within-row reduction.
CPU float64 normalization repairs and the canonical rejection of updating duplicate
rows are explicit in `V8_INTENT_20261023.md`. Non-updating duplicates remain supported.

`v8_indexed.{py,cpp,cu}` constructs union occupancy, other-owner occupancy,
post-tail blockers, release maxima, post lengths and boost flags directly from
rings. `v8_device.py` selects it only under `GPU_SIM_V8_INDEXED=1` on CUDA;
default execution retains the old path. Release-aware traversal/ranking stay in
the established v8 implementation. No static-FLOOD substitution for v8 was made.

`v8_bench.py` switches both geometry and v8 flags per arm, keeps static FLOOD fixed,
checks independent CPU outputs/carry outside timing, exports replayable tensors
including boost/config/carry/Q/mask/lambda, and separates plain complete ticks from
exclusive stage diagnostics. Common-action proof compares complete simulator
tensors; descriptive closed-loop digests do not establish CPU gameplay identity.
