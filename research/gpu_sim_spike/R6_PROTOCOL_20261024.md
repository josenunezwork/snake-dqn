## Cells and measurements (`r6_bench.py`)

- **Ladders:** main E1024, E2048, E4096; canary E64/128/256; Mac smoke E1/2/4. Order: per roster
  (frozen, mixed, scripted), ascending E, with release between cells.
- **Mapped proof:** from reset, 3 progressing ticks (2 in smoke). After each tick, a SHA-256 per world over
  every world-indexed simulator, vector-runtime and collector field, plus that world's action-grid row and
  hero Q/legal rows. The count of world-ticks that differ from the mapped base world is recorded. Base-E
  digests are stored in the base unit so a resumed attempt can still map larger E.
- **Equal completed work:**
  - 3 warmup progressing ticks, then 3 blocks (1 in canary/smoke);
  - each block: reset once, then `8 × (E_max / E)` progressing ticks, so 32,768 world-steps per block in main;
  - complete world-steps/s = work / synchronized block wall;
  - block final state digests within a cell must be equal (otherwise INVALID).
- **Memory:** peak statistics are reset after release and before the build. Physical peak = (device total −
  free − reserved, measured before the build) + peak reserved. Headroom = 1 − physical peak / device total.
- **Native parity:** I0's MOVE2/geometry native proof (`integration_native.run`) runs before any cell.
- **OOM:** recorded as an `OOM` unit, which makes the run INCOMPLETE.

## Pre-registered decision (`r6_analyze.py`), exactly round-36 R6

`KEEP_E4096` only if **every** roster has all three of:
1. `median_rate(E4096) / median_rate(E1024) − 1 ≥ 0.25`;
2. exact mapped outputs at E4096 (zero mismatched world-ticks);
3. measured physical-memory headroom ≥ 0.20 at E4096.

Otherwise `DROP_E4096`.

INVALID covers a native failure, nondeterministic blocks, a producer failure record, or a foreign or
duplicate unit. INCOMPLETE covers any OOM or missing cell. Descriptive only: E2048 gain, exactness and
headroom; every block rate; tick times; peak memory.
