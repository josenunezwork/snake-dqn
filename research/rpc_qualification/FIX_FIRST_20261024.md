- F3: prospective recovery uses operation/request identity, monotonic wall time,
  durable final replies, and an exact marker census. Historical inference is
  explicitly limited to the historical projection mode.
- F4: a child-only nonzero exit fails the session without C3. Independent release
  or cleanup failures still count as C3.
- F5: faults in either required prerequisite arm refuse the attempt before lane
  registry publication. Mandatory injection faults also fail the L4 verdict;
  an undispatched optional CPU loop series remains `NOT_RUN`.
- F6: regenerated fake-CLI proof binds the current transport and recovery tests.
  Preparation, wave preflight, offline verification, and verdict validate its
  complete source map against both current and package-pinned bytes.
- ACCEPT coverage: the reviewer must bind the exact package commit and complete
  mechanically enumerated gate/transport source inventory before prerequisite or
  profile execution. Transport commit and package commit are separate identities;
  their transport subtree must agree.
- Permanent-probe SHOULD-FIX: a scoped qualification policy normalizes the
  terminal exception once, retaining only transient errors and exact helper
  exhaustion. Both the prerequisite and profile broker install it for their
  run and restore the frozen function afterward.
