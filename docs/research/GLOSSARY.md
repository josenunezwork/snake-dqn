# Research glossary

As recorded through **2026-10-08**. [Current state](../STATUS.md) · [chronological sources](INDEX.md).
Definitions describe the named protocols; thresholds are not interchangeable across studies.
Read branch-only files with `git show branch:path` using the references below or in the index.

| Term | Meaning in this project | Source |
|---|---|---|
| **Phase R** | Fresh-world, multi-training-seed replication-style Tier-1 screen. Paired candidate/incumbent (and registered control) games across frozen, scripted and mixed opponents. A GO buys further qualification, never promotion. | [Sequential design](sequential_phase_r_design_2026-10-07.md); `frp-v3:research/frp_v3_20261005/README.md` |
| **Strict gate / Tier 2** | Governed promotion evidence for one frozen candidate against the incumbent, using fresh worlds, a pre-registered plan and independent audit. Passing still requires serving qualification before release. | [Governance](governance_tiers_2026-09-26.md); [FRP3 strict result](frp3_strict_result_2026-10-06.md) |
| **Tier 0 / Tier 1** | Saved-data diagnostics / development screens respectively. Neither changes defaults or becomes Tier-2 evidence retrospectively. | [Governance](governance_tiers_2026-09-26.md) |
| **LH-1** | Long-horizon Tier-1 screen before strict qualification, 48 fresh paired H10000 worlds/mix with H5000 prefix controls. Ratified 2026-10-05: C2 is descriptive; C3 binds at mass ≥300. Labels include CLEAR, REASON_REQUIRED and BLOCK. | `lh1-screen:docs/research/governance_amendment_long_horizon_screen_2026-10-04.md` (ratification footer overrides draft opening) |
| **H5000 / H10000 / MI10** | 5,000-/10,000-frame scoring horizons; MI10 is mass integral at H10000. Mass integral averages over the total horizon, with dead frames zero, not just frames alive. Nested H10000 episodes also record their H5000 prefix. | [Sequential design](sequential_phase_r_design_2026-10-07.md); LH-1 amendment |
| **HK pooling / LB90 / UB90** | DerSimonian–Laird random-effects pooling across training seeds with Hartung–Knapp (`hksj_floor`) uncertainty; each seed first combines paired deltas across mixes. LB90/UB90 are one-sided 90% bounds (ends of a two-sided 80% interval), not SEs. | [Sequential design §1](sequential_phase_r_design_2026-10-07.md) |
| **NI** | Non-inferiority against a specified margin. M2/M2b used LB90 > −15; this is not the strict survival margin. | Claude `redesign-scope.md`; [current state](../STATUS.md) |
| **OBF / sequential looks** | O'Brien–Fleming spending for GO efficacy across pre-registered interim analyses; Phase R KILL/NO_GO use Pocock-type spending. Phase R uses roughly 1/3, 2/3 and full information; look indices can be zero-based. Only a CONTINUE receipt permits the next look. Existing fixed-N studies remain fixed-N. | [Sequential Phase R amendment](governance_amendment_sequential_phase_r_2026-10-07.md) |
| **NO_GO_EARLY** | Optional registered futility stop when the repeated upper bound is below gateable effect G (default 50 at cap 600). It does not resolve final-only PARTIAL/RECIPE/KILL labels; estimates after early stop are descriptive. | [Sequential design](sequential_phase_r_design_2026-10-07.md) |
| **Survival band v2** | `pooled_ni_continue`: pooled survival NI margin 0.05, per-mix NI margin 0.075 (LB > −0.075), absolute survival floor 0.30, repeated `rci_obf` intervals; continue on a band failure. Ratified before FRP3 strict. Its scripted LB −0.060 would have failed the former per-mix 0.05 band. | [Amendment](governance_amendment_survival_band_v2_2026-10-06.md); [disclosure](frp3_strict_result_2026-10-06.md) |
| **Fidelity checks** | Study-specific pre-training checks that intended rescaling, warm starts, simulator/training wiring and hazard constraints preserve the registered contract. F1/F2/etc. are package-local names, not universal check definitions. Passing fidelity is not a scientific result. | `frp-v2:research/frp_v2_20261004/protocol.md`; `sight-widen:research/frp_v5s2_20261009/README.md` |
| **Identity check** | Replay comparison across implementations, commits or platforms. Prefix identity verifies direct H5000 versus a nested H10000 prefix; Mac↔pod identity checks transfer. Neither is established by similar aggregate means. Exact float32 Q ties can flip argmax across BLAS backends; the recorded tie-explaining fix needs pre-registration. | `diag-divergence:docs/research/mac_pod_divergence_diag_2026-10-07.md`; Claude `mac-pod-float-ties.md` |
| **Per-world platform rule** | Candidate, incumbent and controls for a paired world run on one worker/platform; heterogeneous CPU placement must not break the pair. This does not itself establish Mac↔pod identity. | [Strict-on-RunPod amendment](governance_amendment_strict_on_runpod_2026-10-05.md) (ratification Pending) |
| **v8 veto** | Released λ=8 space preference plus head avoidance around the vector policy. The veto remains v8 after the frp3-s12 checkpoint swap. A student evaluated without it must be distinguished from student+v8. | Claude `apex-veto-v8-strict-pass.md`; [release](frp3_serving_result_and_release_2026-10-06.md) |
| **frp3-s12** | FRP-v3 arm M3 seed 12 checkpoint at 60,000 updates, SHA prefix `eec144bf`; served with v8 since 2026-10-06. | [Release](frp3_serving_result_and_release_2026-10-06.md) |
| **champion / incumbent** | `champion` is the older A5 checkpoint/rollback selector. The incumbent after the release is frp3-s12+v8. Historical comparisons against champion+v8 must keep that baseline. | [Release](frp3_serving_result_and_release_2026-10-06.md) |
| **vector61 / sight 67-D** | Feedforward policy's 61-feature observation; S2 adds six sight inputs. The vector61 research line is frozen; 67-D is the default only if reopened, not a released replacement. | Claude `frp-v5s2-recipe.md`, `standing-decisions-2026-10-08.md` |
| **ego2s-b** | M2b's revised ego-raster observation: adds enemy next-cell/path, nearest-two enemy position/size/heading/boost, approach/kill opportunity and uncapped per-move region sizes. The student is distilled DQN, not the earlier PQN line. | `redesign-scope:docs/research/redesign_scope_2026-10-07.md`; Claude `redesign-scope.md` |
| **GridBatchSim / BatchSim** | GridBatchSim extends the bit-exact BatchSim with vectorized occupancy-grid collisions, masks and food. M1 recorded 72/72 full-state H5000 parity; speed depends on workload and lockstep world count. | Redesign scope above |
| **DAgger / distillation** | Aggregate examples from student-visited states and fit a student to the teacher. M2 used raw Q regression plus v8-action margin; M2b added Q-difference and soft-preference losses. Agreement or fit alone is not gameplay qualification. | Claude `redesign-scope.md` |
| **M1 / M2 / M2b / M3-B / M3-C** | Redesign milestones: simulator/observation parity and throughput; initial distillation; revised-observation distillation; multi-seed RL; next stronger RL design. The M3-B slope PASS and later Phase R NO_GO_EARLY answer different questions. | [Current state](../STATUS.md); redesign scope above |
| **G1 / Gate 1** | Redesign throughput milestone (≥20k hero steps/s/process), distinct from the strict promotion gate. M1 met it with scripted opponents; vector61 gate opponents were costly. | Claude `redesign-scope.md` |
| **GO_S_RECIPE / KILL_H / PARTIAL** | Exact study-local outcomes: adopt S2's recipe without promotion / close the tested horizon bundle at its registered dose / FRP-v4's inconclusive category. Do not convert these into generic PASS/FAIL or reinterpret them using later rules. | [Current state and source notes](../STATUS.md) |
