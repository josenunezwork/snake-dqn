## Repair and tests

The native timer still fires at the existing completed-work timeout (900 seconds
in science). A private standalone stdlib helper receives absolute monotonic
deadlines only on meaningful progress. Before arming/cancelling the native timer,
the parent arms this independent process for the same deadline plus a fixed
0.25-second diagnostic grace. At hard expiry it performs no logging, filesystem
I/O, traceback, target Python evaluation or GIL acquisition: it verifies it still
has the target as its parent and sends SIGKILL. EOF disarms, healthy close reaps,
and a failed/dead helper refuses progress. Progress pipe writes are atomic and
nonblocking. Both C/T and TRAIN-01 future sparse source closures include the
helper, because stall_watchdog.py is shared. Existing sealed TRAIN-01 bytes and
running jobs are untouched.

The heartbeat test keeps the same 0.6-second work timer, five-second subprocess
bound, minimum heartbeat count, timeout dump and last-progress assertions. Its
exact permitted termination statuses reflect both implemented paths: _exit(1)
or SIGKILL. Deterministic twins fill a real private pipe to block faulthandler,
then hold the GIL in PyDLL.sleep or call close (which joins the stuck dump).
The independent guard must terminate both faults with SIGKILL inside the same
five-second bound; healthy twins must exit 1 with real stacks. Healthy rearming
crosses multiple old deadlines, closes/reaps the guard and survives a later old
deadline. Dead-helper and failed-start cleanup are also checked. No timeout or
scientific threshold is relaxed. Required 50x loop, broad suites, two consecutive
packet preflights and two consecutive real science wrapper dry-runs are recorded
