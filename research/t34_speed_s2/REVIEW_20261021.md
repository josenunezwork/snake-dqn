## Findings and fixes

1. **Fallback proof gap:** existing tests/receipts had no `_Missing` fallback rows.
   Added a forced missing-table regression after a local replay plan has been built;
   it checks stock actions, hook counters, full digest, and audited fallback counts,
   ensuring no partially staged counter plan is committed.
2. **Audit failure and root-routing proof gaps:** added deliberate counter corruption
   that must raise `NativeV8Mismatch`, plus a checkpoint-free registered-root/clone
   scope test. Scored roots remain on Python by default.
3. **P2 prepared-respawn coverage defect:** the old `_Events` counted births only
   across `BatchSim.step`, while prepared selectors respawn before that step. It now
   wraps both actual BatchSim/Grid `_respawn_dead` implementations and removes the
   step-level birth increment. Four checkpoint-free regressions cover both classes,
   world/branch attribution, repeated preparation, raw-step double counting, and
   restoration. Old zero respawn counts were incomplete evidence, not proof of no
   respawns. Old receipts remain unchanged. The independent reviewer checked this
   fix at `1bb32a92` and found no actionable issue.
4. **Timing-report weakness:** `identity.py` selected independent minima. Its v2
   report now uses per-fixture medians for row costs and pooled speedup. Explicitly
   named minimum fields remain for inspection; historical v1 receipts are unchanged.
   A regression demonstrates minima reversing an apparent result while medians give
   the expected ratio. D3 uses whole S0 round medians, not those older minima.
