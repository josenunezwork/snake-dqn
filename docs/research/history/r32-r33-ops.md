## What Was Learned

- **The Colab CLI supervisor pre-creates the attempt output directory:** a lifecycle guard that demands a non-existent directory fails on the runtime; the guard must accept an existing *empty* directory and refuse anything else.
- **Same-pin canary proof is binding:** a PASS canary on `c1ab2750` cannot admit a `4f11670a` main; the package refused rather than weakening the gate.
- **Synthetic rehearsal is not readiness:** every R32/R33 document keeps strict, registry, serving and product qualification as separate blocked obligations.
