## Implementation / execution steps

1. Implement the new mechanics-v2 rectangular Watch/Play evaluation profile: train_mode=false, allow_respawn=true, hero terminal overlay, frame_rate=1. Keep legacy v1/custom comparisons named diagnostic profiles.
2. Separate evaluation horizon from observation-progress normalization. Initial profile uses 5000 for both but must propagate and fingerprint each independently.
3. Use one post-step logical-mass integral with dead frames zero. Propagate complete config and exact food/boost/kill/death events; do not infer food from net growth.
4. Implement shared versioned scripted anchors and roster/action adapters for deterministic engine parity. Preserve legacy product scripted policy behavior under its existing profile.
5. Implement temporal entrapment and named denominators where feasible; unavailable metrics must be null/unavailable, never numeric zero. No behavioral promotion band is invented from uncalibrated values.
6. Use immutable E0 inputs and versioned inference. Additional mechanics defects found by parity return to ENV through a scheduled handoff; do not silently change written game rules.
