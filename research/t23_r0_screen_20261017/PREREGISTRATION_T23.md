# T23 pre-registration: R0 N=3 static-pool learning screen (2026-10-17)

Written and committed BEFORE any T23 training data exists. Source of the rules:
`docs/research/advice/2026-10-17_h100_preruns_rl.md` sections 4 and 6 (Astra RL advisor), adopted unchanged
except where stated. Plan context: `docs/research/specs/h100_preruns_plan_2026-10-17.md` step 7.

## Question

Does B8 fine-tuned for 8M learner transitions with 3 learner seats against the static six-policy frozen pool
(R0 recipe) beat released B8 in fixed-opponent H5000 play, enough to justify a long league run?

## Training (Colab A100-SXM4-80GB, one runtime, sequential seeds)

- Code: main at the commit that adds this file (trainer commit a049e92 or later with no trainer change).
- Init: B8_s3_final.pth (sha256 3e64978337b67b7acaf4daa93bdefa827d8296bcb0f63413886a1aaad12eb4f8), weights-only
  warm start (fresh Adam, empty replay), exactly as the T16 bundle.
- Seeds: **7101, 7102, 7103, 7104, 7105** (collision audit: no prior use in research/, docs/, scripts/).
- Recipe R0: fp32, `--batch-scale 2`, no LR scaling, 256 transitions/update, `--reward mass --mass-kappa 1.0
  --kill-scale 0 --gamma-end 0.998 --gamma-anneal-end 8000000 --mixed-frac 0.25 --anchor-mode v8margin
  --onpolicy-labels --label-frac 1 --obs-version bv8 --v61-backend numba --learner-fast`, compile
  reduce-overhead, `--learner-seats 3`, static pool (B8, frp3-s12, frp3-s12+v8, champion+v8, scripted greedy_food,
  scripted random_safe), 128 worlds, **6 actors**, raw rings in /dev/shm, `--gather-threads 3`,
  `--actor-queue-frames 2`.
- Length: exactly **8,000,000** learner transitions (`--transitions 8000000`); checkpoints at 2M, 4M, 6M, 8M
  (`--checkpoint-every 2000000`); copied to Drive `t16_colab/t23-r0/seed-<s>/`.
- Actor count deviation: the advisor's rank-2 actor qualification was not run on this roster; a6 is fixed
  here from the a100-n3-01 measurement (actor-bound, lag mean 0.88 / p95 1). Recorded as a deviation.

## Tripwires (training-time, KILL the seed's arm if hit)

Non-finite loss/Q/gradients or trainer halt; >90% one-action share in a full 100k learner-action window
(existing trainer check); greedy boost >2% overall or >1% below length 700 in any full 100k window. The
low-boost floor rule is NOT evaluable (support counts not instrumented) and is reported only.

## Evaluation (Mac, after all five seeds finish)

Terminal hero H5000, fresh paired worlds per seed, distinct between seeds, paired across candidate and B8:
**64 scripted / 32 frozen / 32 mixed** worlds per seed; fixed opponents; only the hero changes. Primary: full-horizon
mass integral (dead frames zero). Also alive-frame fraction and no-death episode survival. Only the **8M**
checkpoints decide; 2M/4M are descriptive. World banks are generated by a new wrapper with its own seeds and
profiles (not T7's producer), collision-audited against strict banks before use.

## Decision rules (section 6, R0 only)

Per seed, average the three mix means equally; G = candidate − B8 mass; one-sided 90% Student-t across the five
seed effects (df 4).
1. INVALID/INCOMPLETE: missing rows/hash/seed identity, unclean exit, sample-count mismatch.
2. KILL: any tripwire; or pooled alive-frame difference vs B8 < −0.03 in any mix, or any seed's scripted
   difference < −0.15, or pooled no-death episode survival < 0.50 in any mix; or upper90(G) ≤ 0.
3. GO (long-run planning only): lower90(G) > 0, mean G ≥ 20, scripted mass point ≥ 0, ≥4/5 seed effects > 0,
   all guards pass. Not a strict pass and not a release.
4. EXTEND once if neither: freeze checkpoints, add 64/32/32 new worlds per seed, recompute under the same rules;
   then INCONCLUSIVE if still neither.

No extra training, no best-checkpoint swap, no seed replacement after data.
