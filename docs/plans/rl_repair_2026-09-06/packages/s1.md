## Implementation / execution steps

1. Atomically enable v3 inference dispatch with its loader/producer support. Add ID-aware action-value access so inspector calls, epsilon skips and mixed rosters cannot consume another snake row. Preserve legacy checkpoint preparation and tie rules.
2. Route v3 AISnake selection through legal/advisory resolution before movement; do not let the legacy normal-only fallback override the new resolved boost options. Keep legacy vector/v2 mask behavior by explicit contract. Supply the collector with explicitly tagged current/next mask semantics for A2; legacy collected advice remains legacy.
3. Serialize actual legal/advisory/resolved masks and contract/hash identities. Use weight-shape inference for bare 58-D checkpoints; label untrained Watch startup or fail readiness when the champion is absent.
4. Use the named mechanics-v2 rectangular Watch/Play deployment profile. Reject unsupported arena/observation/action/normalization semantics. Treat explicit training-to-deployment distribution differences as recorded provenance; legacy incumbent deployment is pinned, not silently inferred.
5. Provide a bounded headless serving spot-check entrypoint with disposable output paths. It runs only when the root grants a compute slot.
