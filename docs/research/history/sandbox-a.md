# Sandbox Job A GPU-Resident Throughput and Scale Assay (A-1 -> A-2 -> A-3)

## Question and Goal

How can A100 development experiments run at full velocity without per-job judge ceremony while strictly protecting confirmation/held-out evaluation banks from data leakage, and what limits end-to-end GPU-resident `DeviceSim` rollout collection + PPO learner throughput across `E128..E4096` (`A-1 -> A-2 -> A-3`), as the prerequisite for long GPU-resident on-policy runs (`TRAIN-01`)?

## What Was Learned

1. **Architectural sandbox guardrails replace per-job prose ceremony**: Enforcing input allowlists (`SANDBOX_INPUT_REGISTRY.json`), domain-separated `a100-dev/` seed namespaces (all `22,457,142` seed values checked by searching the already-sorted unique array), and a single-checkpoint Mac crossing gate eliminated per-run judge reviews without risking confirmation-bank leakage (`docs/research/governance_a100_sandbox_20261026/ADOPTED.md`, `research/sandbox_a_resident/A3_ADMISSION03.md`).
2. **GPU-resident rollout collection was bottlenecked by reset food loops, unbatched anchor seats, and per-tick truncation syncs**: Learner updates on `Ego2sNet` (`~140k` rows/s with TF32 and `2,048`-row minibatches) were never the bottleneck; removing per-tick host syncs, vectorizing partial resets and initial food placement, batching the 5 opponent anchor seats, and scaling to `E1024–E4096` with prewarmed `R2` buckets lifted integrated collection + PPO throughput by about **`11.9x–15.9x`** (A-1 `E1024` integrated `1,771.6` -> A-3 compiled `21,133` at `E1024` / `28,113` at `E4096` hero rows/s; derived) (`research/sandbox_a_resident/README.md`).
3. **`torch.compile` validation must run in a single TF32 mode with prewarmed static R2 buckets**: Compiling separate `TF32=False` validation graphs (`A3_RESEAL02.md`, rejected) doubled compilation work and risked lazy recompilation during timed cycles; validating against a no-grad eager reference in the caller's TF32 mode and prewarming all 4 static `R2` window buckets (`256/512/768/1024`) before warmup eliminated mid-cycle compiler activity (`research/sandbox_a_resident/A3_RESEAL03.md`).
