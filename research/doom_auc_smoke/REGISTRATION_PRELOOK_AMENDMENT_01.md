# Pre-look amendment 01 — enriched roots and interpretation — 2026-10-30

Status: owner-directed before the registered main fit and before the scoring
look; existing labels are sealed and no new label/metric is examined here.
This adds descriptive reporting and interpretation only. Original bytes stay intact.

The searched root sample is **death-lookback-enriched**, rather than a natural
sample of states encountered during play. A GO is an **UPPER BOUND** learnability
screen on this enriched bank, not natural-state danger AUC. This is an
interpretation limitation, not a mathematical upper confidence bound on an
unobserved natural-state AUC. Root selection and the easier between-kind
separation may inflate pooled discrimination. GO does not establish within-kind
discrimination, calibration, gameplay improvement or a serving qualification.

At the same single Mac scoring look, report descriptive AUC for ordinary and
death_lookback roots separately, at L>=600 and all lengths, for pooled legal
actions, stored B8 action and each individual action, for both arms and their
paired difference. Retain the registered binary suffix expansion, legal masks,
parent-world bootstrap draws and two-sided 95% percentile CIs. Report undefined
AUC/CIs and positive/negative parent-world support; sparse strata do not change
the primary support rule or GO/GRAY/KILL bars. No additional look, selection,
training or inferential decision is allowed from these splits. Root kind remains
Mac-only metadata and never a target or model input.

Before GPU spend, count assessment roots with L>=600 by parent world and root
kind using only the frozen bank metadata. Report all assessment parent worlds,
including zero-support worlds, alongside the >=10 positive AND >=10 negative
parent-world requirement for EACH primary endpoint. Ten eligible worlds is a
necessary condition only: the same worlds can contain both classes. Label-free
counts cannot guarantee class support or >=95% defined bootstrap replicates;
INCOMPLETE_SUPPORT remains possible and is not a science failure. No labels are
opened to improve this forecast or alter N/the split.

Overfitting limitation: the spatial model has 630,182 parameters and only 2,048
training roots. 3,000 updates x batch 32 = 96,000 root draws, or 46.875 (~47)
training-set equivalents sampled with replacement. World-disjoint assessment
limits direct leakage but does not eliminate finite-bank overfitting or
selection bias. Only final update 3,000 is scored; there is no validation-based
early stopping or best-checkpoint selection. This fixed schedule can overfit or
underfit, and a weak result does not isolate representation capacity from
optimization. No recipe changes or intermediate-checkpoint substitution follow.

All registered primary endpoints, support thresholds, models, schedule, labels,
data identities, seeds, caps, look discipline, decision bars and release scope
remain unchanged. The existing Mac scoring-look lock is retained.
